# 平台适配与迁移

本技能采用UTF-8 Markdown和相对链接，主文件仅使用name、description元数据，不包含特定平台插件接口、脚本依赖或固定磁盘路径。平台名称不决定业务规则，以本次实际可用的能力执行。以下是能力适配办法，不是各产品当前安装界面的操作保证。

## 启用方式

1. 对能加载本地Skill目录的平台：将整个`sinocipher-news-weekly`文件夹放到该平台指定的技能目录或导入入口；不要只复制SKILL.md。宿主提供按名称调用时使用`sinocipher-news-weekly`；是否需要美元符号或其他命令取决于宿主。
2. 对支持文档/知识文件的对话平台：若其支持压缩包读取可上传整包，否则先解压，提供SKILL.md、关联参考和sources目录清单。明确要求按主文件执行；确认链接对应文件实际可读，不能只上传入口后假定平台自动取得其余文件。
3. 对只能提供文本上下文的平台：按任务加载主规则、业务范围与分类、相关核验/写作参考及本轮来源清单；缺少来源清单正文时不能宣称已按清单执行。不要求用户存在原作者电脑目录。

可直接使用同一自然语言请求：“使用sinocipher-news-weekly，按指定起止日期、包内来源清单及所附参考，围绕数据安全、密码技术（包括零信任）和CA，先按价值与热度筛选6—10条正文，再按资讯属性分类，并与提供的往期去重。”示例不含待执行日期；实际窗口由用户任务提供。

Codex、Claude Code、WorkBuddy等文件代理可按可用的本地文件/浏览能力适配；ChatGPT、Claude、Gemini等对话环境按本次可读附件、联网和文件交付能力适配。不能仅凭产品名称假定某工具、权限或引用方式可用，也不要求安装某一供应商SDK。

## 能力映射与降级

| 需要的能力 | 当前平台可用时 | 缺少该能力时 |
| --- | --- | --- |
| 读取规则、来源和参考 | 本地文件读取、附件解析或文档工具；相对路径均以技能目录为基准 | 先找已上传的关联文件；必要材料仍缺则请求其正文，不能重建白名单或漏读参考后称完成 |
| 浏览官网栏目、读取原文及附件 | 用浏览器、网页读取、搜索或已授权连接器；关键词只补漏 | 可处理用户提供的可核原文及历史已读证据；无实时访问能力时不能交付为已核最新检索结果 |
| 日期辅助过滤 | 工具支持时按完整窗口过滤，再核原始日期 | 用栏目分页和原页日期判断，不依赖d7/d10/d14等特定参数，也不缩短用户窗口 |
| 公开网页备用读取 | 有终端、网络且适合时，可尝试Python/PowerShell或平台等效请求 | 换其他官方页面、附件或可靠完整转载；不要求安装Python，不把不可用的备用方式列为已经使用 |
| 留存历史与核验记录 | 写本次输出目录的报告、证据摘要及可选成果索引 | 没有文件写入能力时，在独立内部上下文保留可追溯记录；若无法持久化，不承诺下次可自动读取，当前文章仍可聊天交付 |
| 文件交付与预览 | 保存Markdown，用宿主可用链接、附件或预览交付 | 直接在对话输出完整一篇；不因缺少某展示命令阻塞，也不拆独立备选正文 |

不能联网又未得到足以核验的新材料时，交付已核内容或候选草稿，明确缺口；不靠知识截止、搜索记忆或模拟网页填本期新闻。引用显示遵守宿主要求；业务稿底部仍保留可追溯的事项与实际来源。

## 历史、工作区与能力边界

用户给定输出位置优先，否则使用当前平台的可写工作区或聊天交付。日志索引可用于跨期去重，但仅在本任务已有可用记录且适合维护时使用；不强制存在MEMORY.md，不自动改写全局记忆，不因索引缺失丢弃本次已提供的往期。只对实际取得历史作去重声明。

每次记录本轮实际来源版本、已读证据、读取方式、官网覆盖、参考去向和审稿修正。已有可追溯证据可复用，但不能将复用说成本轮新读取。访问失败时换适用读取方式，避免无限重试；不存在统一“20秒后请用户确认”的业务步骤。确需用户输入时指出具体缺少什么。

清单里的“每日/每周关注”只是优先级参考；常规执行不表示已建立自动化、常驻爬虫、全站档案或跨平台同步。只有用户另行要求相应机制时才配置，不在Skill导入时自动创建。
