# 常规周览与速览模板

周览、速览使用同一单篇结构。先按业务相关性、信息价值与实际热度筛选全篇6—10条正文，再按七类资讯属性归类；分类不是检索配额，没有入选内容的栏目不展示。每类不设数量下限或上限，不再使用四方向结构。

文件名可用“中安云科安全周览_日期区间.md”，公司名、名称及交付位置按用户要求。仅聊天交付时也输出完整单篇。

## 文章顺序

1. 概要式热点总标题。
2. 最近一周热点导览：至少4条不同热点，每条通常约40—60字，普通文字分段，无加粗、无行首列表符号或编号，与总标题有信息差。
3. 实际有资讯的属性栏目：使用[已确认的七类名称](directions.md)，栏目标题按展示顺序用“一、二、三……”编号。每个栏目内按价值排序，资讯标题从“1.”重新编号；单条正文不超过200字，时间融入事实叙述，评论在对应栏目新闻之后。
4. 必要的集中说明。
5. 未采用资讯说明：用户参考和进入实质筛选的未选候选在本篇底部交代具体原因，不另附备选正文。
6. 内容来源说明：按实际采用的机构/渠道列对应事项和原始链接，区分转载与原发；不逐条另加来源或发布日期栏。

正文总量只计算去重后的独立事件，标题、热点导览、小编评论及文末说明不计入。只展示三个栏目也可以达到6—10条，不为凑栏目而补消息，不将同一事件复制或拆分增加计数；不足6条须按核验规则继续补查，仍不足明确为待补齐草稿。

## 未采用说明格式示例

以下为虚构条目，仅示范去向写法，不作为新闻材料。

| 资讯主题或参考编号 | 处理结果 | 具体原因或去向 |
| --- | --- | --- |
| 参考2：某旧通知转载 | 未采用 | 本期只转载原通知，没有新增要求或实质动作。 |
| 参考4：某研究 | 本期择优未选 | 已核实，但全篇已有10条价值更高的消息。 |
| 参考6：某截图 | 待核 | 尚缺原发布主体及可读全文，未作为确定新闻入稿。 |
| 参考7：重复标准报道 | 合并采用 | 已融入标准规范与技术指南栏目对应条目，不另计数，不算排除。 |

没有未采用、待核或需解释的合并候选时可省略该节，不虚构排除记录。来源说明只列实际使用的证据，不复制整份渠道清单。详细核验过程留内部，必要说明统一置后。
