【置顶专题】电子认证合规整改倒计时：10月30日是硬节点 本期最高优先级 · 与公司主业直接相关

⚠ 过渡期 2026年10月30日到期，逾期将被监管处理

新版《电子认证业务规则规范》（T/CQAE 11034—2025）推动的电子认证服务机构合规改造，过渡期截至 2026年10月30日。这是本周期内唯一一个"过期不可补救"的时间节点。过渡期结束后：机构须对外公示新版 CPS 并按其开展服务；主管部门将组织专项检查核验改造落地情况；对逾期未完成整改、不符合规范的主体，依据《电子签名法》《电子认证服务管理办法》实施监管处理。

监管动作节奏（10月）：10月14日，工业和信息化部信息技术发展司组织召开电子认证业务规则规范改造工作推进会，全国 58 家电子认证服务机构主要负责人参会，CFCA 等多家重点机构汇报改造进展，信息技术发展司王威伟副司长作总结讲话。会议明确四项要求：①核心职责不得委托、按期完成改造；②加强能力建设、守牢数据安全底线；③推进与应用方协同改造、加快联调测试；④做好风险防控，杜绝盲目停服、粗暴停服、无序停服。

新规三大关键导向（CFCA 10月26日公开解读）：

① 法定职责归位——服务告知、身份核验、意愿确认、认证协议签署、数据留存等关键法定环节，由持牌 CA 机构直接完成，不得委托；② 协同定位清晰——合作伙伴仅承担客户服务保障、业务咨询引导、系统对接转发等辅助性工作；③ 证书分级管理——电子签名认证证书划分为高等级与基础级两类，对应不同核验强度，匹配不同风险等级的业务场景。

监管逻辑的变化：从"机构合规"走向"生态合规"。整改责任已延伸至业务链条——认证机构须向金融机构、电子合同平台、互联网平台等全部合作方出具书面告知，明确整改要求与时间节点，且上下游协同工作须在 10月30日前落地完成。同时明确禁止两类规避行为：不得借合同约定把电子签名认证服务变相转为安全服务或辅助认证服务；不得把第三方认证服务违规改造为自建项目。

对中安云科的直接意义

  • 内容侧：这是一个现成的热点选题，且我方有天然话语权。10月30日节点当天/次日发一篇《CA 新规过渡期收官：企业侧要跟着改什么》，讲"证书分级管理"和"合作方书面告知"这两件跟客户切身相关的事，比讲技术概念更容易被转发。
  • 商务侧：这是存量客户回访的合理由头。凡是走我方证书/签章通道的集成商、平台方客户，10月底都应收到一次"合规改造完成情况确认"，顺带排查续费与扩容。新规要求认证机构向全部合作方书面告知——这条落地动作本身就是一次客户触达机会。
  • 投标侧：注意"不得变相转为安全服务"这条红线。过去部分项目靠"安全服务包"绕开 CA 资质要求，新规明确堵死。反过来看，这对持牌机构是利好——我方可在方案里把"持牌 CA 直接承载法定环节"写成合规优势条款，形成对非持牌集成商的差异化。
  • 培训侧：《电子认证业务规则规范》培训视频口播稿的"新规要点"章节，可直接采用工信部推进会四条要求 + 新规三大导向作为骨架，比自行归纳更权威、更不易出错。

智慧安全 4.0 的三层结构：①智能原生底座——把 AI 作为安全架构的基础能力，把可信安全内嵌为 AI 系统的固有要求；②持续进化——让大模型与智能体在对抗中迭代学习；③自主运营——依托 AI 实现人机协同，搭建 7×24 小时主动防御的自主安全运营体系。

产品侧的"双引擎"划分值得借鉴：一是"AI 赋能安全"，以自研安全垂域大模型"风云卫"为基础，把 AI 融入威胁发现、分析、研判、处置全流程；二是"AI 自身安全"，通过"清风卫"系列构建覆盖事前风险评估、事中实时防护、事后全流程审计的 AI 原生纵深防御体系，为大模型与智能体提供全生命周期防护。这套"赋能 + 自保"的二分法，已经成为头部厂商对外表述的通用框架。

行业判断（可引用的观点）：国家数字交换系统工程技术研究中心主任邬江兴提出，AI 驱动的智能自主攻击正在超越人类专家能力边界，漏洞挖掘、攻击策略全面智能化重构，主张以"构造的科学"破局，推动安全模式从"被动防御"向"构造免疫"升级。绿盟董事长胡忠华表示，智能体逐步具备自主规划、调用工具、执行任务的能力，既能提升检测响应效率，也可能被用于实施更复杂的攻击。

零信任方向的本期判断

  • "零信任"这个词在本周期的厂商叙事里出现频率明显下降，"智能体安全/身份治理"接棒。绿盟、天融信、格尔、芯盾近期的主推内容里，零信任更多作为能力组件出现（SDP、动态授权），而非独立售卖的概念。这与我方内容选题方向的调整是一致的——继续单讲"零信任"已经不带流量，改讲"AI 要进业务，凭什么是它、凭什么到这个数据"，反而有话题度。
  • 注意"AI 自身安全 + AI 赋能安全"这个二分框架已被头部厂商占位。我方如果要进这个赛道，宜从自己最有优势的点切——密码是 AI 可信运行的基础支撑（格尔的表述也是这个逻辑），而不是去和绿盟比大模型安全护栏。

三、身份安全方向 身份安全的对象从"人"扩展到"Agent"

芯盾时代 北京芯盾时代科技有限公司 Agentic AI 指南代表性厂商

入选安全牛《自主智能体 Agentic AI 风险治理与安全应用指南》，被评为 Agent 安全代表性厂商。指南把身份认证与权限治理列为六大核心安全能力之首，给出两个核心理由，判断很锋利：

① Agent 权限会被放大——实际能力范围可能超过单一用户或传统应用；② "授权合法 ≠ 行为合法"——攻击者可能并不具备数据权限，却能操纵 Agent 以合法身份完成数据访问和外发。

产品做法：芯盾 AIAM 把 Agent 分为企业助手 Agent、个人助手 Agent、自主 Agent 三类差异化管理，通过令牌交换机制控制"用户 → Agent → MCP、A2A 链式访问"，完整记录"哪个用户通过哪个 Agent 访问哪个 MCP 的哪些资源"，支撑存证、溯源与归因。

这个"三类 Agent 分法 + 令牌交换 + 全链存证"的模型，是目前看到最接近可落地产品形态的智能体身份治理方案。对我方的意义：如果要在统一认证/IAM 产品线上加 AI 场景能力，这套模型可以直接作为需求清单参考。

四、数据安全方向 AI 越权成为新的合规风险点

美创科技 杭州美创科技股份有限公司 AI 越权场景

10月21日发布《AI 数据访问安全 | 如何控制 AI 访问权限，防止越权》场景内容，切入了一个非常具体的痛点：AI 越权。文中案例：某企业"智能问答"AI 助手本用于员工查考勤、查报销，但审计发现其数据库访问记录里出现了薪酬表、绩效表的查询记录——原因是该 AI 助手与另一个内部 Agent 共用同一个数据库账号，通过共享账号"继承"了不该有的访问权限。

合规依据引用得很准：《数据安全法》要求建立全流程数据安全管理制度并采取必要技术措施；《网络数据安全管理条例》第九条明确列出访问控制和安全认证等措施；《个人信息保护法》要求个人信息处理遵循最小范围原则并防止未经授权访问。"相关义务不会因操作者从人变成 AI 而消失"——这句话是极好的传播点。

产品解法：美创数据库防水坝为每个 AI Agent 建立独立访问身份，关联责任人、访问来源和允许使用的数据库账号；AI 从代理地址接入，由托管账号承接真实凭据，真实密码不向 AI 暴露；一 AI 一账号、独立身份、独立授权、行为可追溯；让 AI 的权限跟着任务走，而不是照搬账号权限。

来源：网易号 / 杭州美创科技（2026-10-21）

九、对中安云科的启示

三条行动建议（按紧迫度排序）

  • 【本周内】借 10月30日节点做一轮合规宣传与客户触达。新规过渡期收官是天然的传播窗口，且我方作为持牌机构有立场发言。具体动作：①10月30日或31日发一篇公众号长文，讲证书分级管理 + 合作方书面告知 + 企业侧要做的事；②向存量集成商/平台客户发一次"合规改造完成确认"，附新版 CPS 要点，顺带排查续费与扩容机会；③把"持牌 CA 直接承载法定环节、核心职责不委托"写进投标方案合规章节，作为对非持牌集成商的差异化。
  • 【本季度内】把后量子从"概念"变成"可投标的表述"。目前竞品的对外表述已经明显领先：格尔有 NGPKI + 国产/国际双栈 + 单证书内嵌双公钥 + 信通院抗量子技术验证（首家）；三未信安有后量子迁移率检测专利和 AI 智能体抗量子 MPC 资产托管专利；信安世纪有卫星互联网密钥管理改造。我方若继续只有"支持国密算法"，在新一轮招标的创新性评分上会被压。最小可行的起步动作：①梳理现有产品的密码敏捷性（算法可替换架构）；②对外形成一句清晰的后量子迁移主张；③跟踪 ICCS 84 个候选算法名单。
  • 【持续】盯住"智能体身份"这个新增品类。30天内微软、Okta、ServiceNow、格尔、芯盾、天融信六家在这个方向落子，且已有 T/BFIA 070-2026《智能体技术金融应用安全要求》可作为投标依据。我方的切入角度应该是"证书是非人身份最成熟的可信载体"——不与软件 IAM 厂商比 Agent 行为分析，而是比身份根信任与全生命周期管理，这是我方强项。

风险提示

  • 吉大正元的四连板不代表行业景气，反而要警惕。公司自己公告承认 AI 安全、抗量子、低空经济"收入占比较低，尚未形成规模化收入"，静态市盈率为负。这类估值炒作会带动整个密码板块的情绪，但不会带来真实订单。三季报 10月29日披露，建议关注其对板块情绪的扰动。
  • 信安世纪（ST信安）的激进可能性。其因研发费用资本化会计处理不当被出具内控否定意见而戴 ST，营收和研发投入与三未接近但盈利状况更好、合同金额同比增长。戴帽状态下更依赖新增合同，在 SSL/签名验签等其优势场景可能出现价格战。我方在银行类项目报价前应先摸底其存量装机与维保到期时间。
  • 警惕第三方"选型指南"类内容的排名绑架。10月下旬大量出现付费收录性质的"实力参考/避坑指南"，竹云、芯盾等被反复列入第一梯队。这类内容会影响部分甲方前期短名单，我方在该渠道目前基本缺席。

十、小编评论

本期最该被记住的不是哪个厂商发了什么产品，而是两个日期：10月30日和2027年6月。

10月30日是电子认证合规整改的关门时间。这件事在行业里几乎没有激起水花，但对持牌机构来说是一次真正的洗牌——新规把服务告知、身份核验、意愿确认、协议签署、数据留存五个法定环节全部收回到持牌机构，还顺手堵掉了"变相转安全服务"和"第三方服务改成自建"两条老路。过去靠这些缝隙做业务的集成商，这次是真的没得绕了。对我们是利好，但前提是客户知道我们合规、知道为什么这对他有好处。现在离节点只剩四天，该说的话要赶紧说。

2027年6月是国密后量子算法第一轮评估完成的时间。这条线索比任何产品发布都重要——它意味着后量子在中国正式进入倒计时，而从算法评估完成到产品可送检可投标，行业普遍判断只有12到18个月。格尔软件已经在这个方向上把标签贴满了：NGPKI、国产国际双栈、单证书双公钥、第一家通过信通院抗量子验证、入选安全419年度严选。三未信安把专利铺到了"迁移率检测"这种很实操的位置。我们目前在这条线上的对外表述几乎是空白。

还有一条容易被忽略的：身份安全的对象正在从"人"变成"Agent"。芯盾那句"授权合法≠行为合法"说得挺准——攻击者不需要有数据权限，只要操纵一个有权限的 Agent 就行。微软、Okta、ServiceNow、格尔、芯盾、天融信，三十天内六家在动。这不是概念，因为已经有 T/BFIA 070-2026 这样的标准编号可以写进投标书了。

至于吉大正元的四个涨停，看看就好。公司自己都说新业务"尚未形成规模化收入"，市盈率是负的。真正在赚钱的单子都在招标公告里，不在K线图上。
