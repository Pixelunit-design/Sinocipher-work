# 限制条件与禁止事项（references/constraints.md）

## 硬性禁止

1. **不得编造数据**：金额、日期、证书数、文件号必须有来源；查不到就标"待核实"，不得填补。
2. **不得把单一信源当已核实事实**：厂商自述、自媒体转述必须标注待复核。
3. **不得重复已覆盖内容**：每期与上一期显式去重。
4. **不得替用户发布**：GitHub 仓库（Pixelunit-design/Sinocipher-work）改动由用户自行上传。
5. **不得用 `rm -rf` 等删除个人目录文件**；台账只追加不覆盖。
6. **不得用 sheetagent MCP 打开本地 Excel**（验证失败），用 openpyxl。
7. **不得写含非ASCII路径的 .ps1/.bat 脚本文件**（编码乱码），改用直接命令调用或纯ASCII脚本。
8. **不得增加用户未确认的业务规则**进入对比口径；资质数字以用户确认+官方接口为准。

## 环境限制

- `F:\桌面\市场营销内容\` 已迁移至 `D:\市场营销内容\`，旧路径不可访问。
- 网专（CAC）无公开API，数据依赖用户截图转录；截图原件已不可获取，数字以 context.md §2 为准。
- scctc 服务器为旧版TLS，必须启用 OP_LEGACY_SERVER_CONNECT。
- Excel COM 渲染验证存在"数字+自动换行→####"的老旧bug（cell.Text 实际正常），非文件问题。

## 内容红线

- 不写竞品未经证实的负面内容（监管处罚类须有官方文号，如渔翁400万罚单有江西证监局出处）。
- 涉及国家安全/政策类表述以官方文件原文为准，不做延伸解读。
- 对中安云科的建议章节不得虚构我方产品能力（如不得建议宣称已有PQC产品）。

## 时效声明

本技能包内行业情报快照截至 **2026-11-20**。执行时必须重新检索验证，不得直接引用历史情报当"最新"。
